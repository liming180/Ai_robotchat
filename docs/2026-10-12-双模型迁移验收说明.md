# 双模型架构迁移验收说明

**日期：** 2026-10-12
**范围：** 后端 AI 服务从智谱 GLM 切换为双模型架构（文本 MiMo + 视觉 GPTCODEX）
**结论：** 7 项验收全部通过

## 迁移内容

| 链路 | 平台 | 模型 | 功能 |
| --- | --- | --- | --- |
| 文本 | 小米 MiMo | `mimo-v2.6-flash` | 对话 / suggestions / RAG / tool calling |
| 视觉 | GPTCODEX 中转站 | `gpt-6-luna` | 图片理解 |
| 图像生成 | 无远程模型 | （`LLM_IMAGE_MODEL` 置空） | 本地 SVG 头像降级 |

环境变量统一为 `LLM_` 前缀按功能分组（`LLM_MODEL_*` / `LLM_VISION_*` / `LLM_IMAGE_MODEL`），env 优先、代码不写死；密钥只存在于 `backend/.env`（gitignore），`.env.example` 与 `AI_INTEGRATION.md` 一律 `sk-***` 占位。

## 实测确认的 API 行为

- MiMo 接受 `max_completion_tokens` 与 `extra_body={"thinking":{"type":"disabled"}}`（关闭思考后 `reasoning_tokens: 0`，降低延迟）
- MiMo tool calling 返回标准 `tool_calls` 结构
- 两平台均**无 Embedding 端点**（MiMo `/v1/embeddings` 404、GPTCODEX 403），RAG 按设计使用本地哈希向量（`SimpleHashEmbeddings`）
